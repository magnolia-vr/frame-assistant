Frame Assistant

Steam Frame を PC につないで遊ぶときの便利機能をまとめた、Windows 用の無料ツールです。VR の中で英語を見つめて翻訳したり、英語の音声に字幕を付けたり、時計・タイマー・マイクの状態を表示したりできます。使いたい機能だけを選んで入れられます。

できること

要 アイトラッキング

見つめて翻訳・読み上げ

VR 内の英語の文を見つめると、文字を読み取って日本語に訳し、VR 内のパネルに表示します。日本語で読み上げることもできます。処理はすべて PC の中で行います。

0.6 新機能

英語字幕

PC で流れている英語の音声を文字にして、日本語訳と一緒に VR 内へ表示します。音声も字幕も保存しません。

要 Frame 接続

アイトラッキング

Frame の視線とまばたきを VRChat に送ります。

要 Frame 接続

時計・バッテリー HUD

VR の中に時刻・日付・バッテリー残量を表示します。

Frame なしでも可

タイマー・音声アシスタント

タイマーや時刻の通知を登録できます。「アシスタント」と呼びかけて「今何時」「10分タイマー」「次の曲」などを話して操作できます。

要 Frame 接続

マイク診断・音量調整

Frame の内蔵マイクの音量や音声処理を点検し、音割れするときは音量を下げられます。変更前の値は保存して元に戻せます。

0.6.1 新機能

PC マイクのミュート表示

Steam Streaming Microphone がミュート中かを VR 内に表示し、見つめる・ボタン・声で切り替えます。

要 OVR Advanced Settings

PlaySpace 設定

OVR Advanced Settings の Space Drag（手でプレイ空間を動かす機能）を、右手のコントローラーで使えるようにします。

ほかにも、VR 内のメディア操作（再生・曲送り・音量）、アプリ内通知、翻訳結果を VRChat のチャットボックスへ送る機能、ドングル接続チェック、不具合報告用の診断レポートがあります。新しい機能はどれも最初は OFF です。

動作環境

PC
Windows 11 で動作を確認しています（Windows 10 は未確認）。Python などの追加インストールは不要です。
Steam Frame
PC に接続でき、SteamVR が動く状態にしておきます。
Frame の開発者モード
Frame 本体の設定を変える機能を入れるときに必要です。「設定 → システム」で開発者モードを ON にし、「設定 → 開発者 → Set User Password」でパスワードを設定します。タイマー・音声アシスタントだけなら不要です。
OVR Advanced Settings
PlaySpace 設定を使う場合のみ必要です。Steam で導入しておいてください。
日本語の音声機能
読み上げには Windows の日本語音声、呼びかけでの操作には Windows の日本語音声認識を使います。

導入・使い方

  1. FrameAssistant-Setup-0.6.6-preview.exe をダブルクリックします。ZIP 版は、右クリック →「すべて展開」してから FrameAssistant.exe を開きます。
  2. 「インストール・更新」を選び、使いたい機能にチェックを入れます。「すべて選択」でまとめて選べます。
  3. 初めて使うときは Frame を接続し、画面の案内に従って接続を確認します。
  4. 最後に表示される変更内容を確認して実行します。途中でファイルをダウンロードする機能（翻訳 約115 MB、字幕 約141 MB）は、公式の配布元から取得して中身を確認します。
  5. 完了画面の「操作画面を開く」で、機能ごとのタブが並んだ画面が開きます。「デスクトップにショートカットを作成」を押すと、次からはアイコンから開けます。

使うときのポイント

  • VR 内の翻訳パネルや電源ボタンは、見つめるだけで操作できます。反応までの時間は標準 1 秒で、0.6〜2 秒から選べます。
  • 電源ボタンで表示をまとめて OFF にすると、アイトラッキングは動かしたまま、HUD・読み上げ・音声の待受を止めます。
  • 呼びかけで操作するときは、Windows の入力マイクが Steam Streaming Microphone になっているか確認してください。「アシスタント」と言って一拍置き、「聞いています」と出てから話します。
  • 削除は、セットアップを開いて「アンインストール」から、機能ごと、またはまとめて行えます。

音声・字幕・認識した言葉は保存も送信もしません。マイクや Frame の設定を変えるのは、ボタンを押したときだけです。%LOCALAPPDATA%\FrameAssistant\backups には接続先などが含まれるので、他の人に渡さないでください。

開発者の環境では、次の3点をまだ確認できていません。できる範囲で試して、結果を教えてください。

1. 翻訳を実際に使ってみる

  • 英語の看板・メニュー・チャットを見つめて、翻訳パネルが出るか試してください。
  • 読み上げを ON にして、日本語の音声が Frame から聞こえるか確認してください。

教えてほしいこと：読み取りの正確さ、訳の自然さ、表示までの時間、見つめる操作の疲れやすさ

2. 音声認識の精度

  • 入力マイクが Steam Streaming Microphone か確認してから、待受を ON にしてください。
  • 静かな場所と、ゲームの音や周りの話し声がある場所の両方で試してください。

教えてほしいこと：10回呼びかけて何回反応したか、話していないのに反応したことがあるか

3. まっさらな PC でのインストールと削除

  • このアプリを入れたことがない PC で、インストールから操作画面の起動まで進めてください。
  • そのあと「アンインストール」で削除し、ショートカットや機能が残っていないか見てください。

教えてほしいこと：止まった手順、分かりにくかった画面、表示されたエラーの文言

質問・不具合報告

質問・不具合の報告・機能の要望は、このフォームから送れます。アカウントは要りません。届いた内容は AI（Claude）が読んで自動で回答し、数分でこのページの「回答を見る」に載ります。送信後に表示される受付番号を控えておいてください。開発者（まぐのりあ）にも内容が届き、必要に応じて確認します。

VR の中の様子は、スマホでレンズ越しに撮った写真や短い動画で大丈夫です。PC の画面は Windows の「Win + Shift + S」で撮れます。

回答はこのページに載ります（受付番号を知っている人だけが探せます）。名前・パスワード・接続先の IP アドレス・鍵などの個人情報は書かないでください。
