Steam Frame 用・Windows 対応・0.7.0 試験版

Frame Assistant

Steam Frame を PC につないで使うための、非公式の無料ツールです。0.7 では VR メニューを1つにまとめ、時計・翻訳・撮影・床と位置の調整を VR 内で操作できるようにしました。

0.7.0 preview は試験版です（2026年10月18日公開）。配布ファイルの組み立て時の検査は済んでいます。実機での確認は試験に協力してくださる方と進めている途中です。

0.6.7 から変わったこと

下記はソースと隔離した試験で確認した内容です。実行ファイルとヘッドセットでの確認は残っています。

0.7 で刷新

VR メニューを1つに

左の一覧は英語表示の10ページです。HOME（ホーム）、ANNOUNCE（アナウンス翻訳）、GAZE（視線翻訳）、TIMER（タイマー）、ALARM（アラーム）、SYSTEM（性能）、CAPTURE（撮影）、PLAY AREA（遊ぶ範囲と位置）、SETTINGS（設定）、LAB（ラボ）を切り替えます。レーザーで指し、トリガーで押します。

0.7 新機能

時計と5つの色

上の「CLOCK／時計」で表示を切り替え、水色・赤と金・緑・紫・白から色を選べます。時計・翻訳・メモの色をそろえます。TIMER の「HUD NOTICE／視界への通知」が ON なら、有効なアラームを時計の左、動作中のタイマーを右の板に表示します。アプリ内通知が OFF でも出ます。板は表示だけで、操作は VR メニューで行います。

0.7 新機能

アナウンス翻訳

PC で聞こえる英語のアナウンスを日本語の字幕や読み上げで確認できます。毎回 OFF から開始し、「試しに流す」で試せます。声は Windows 標準です。

0.7 で拡張

見つめて自動翻訳

文字を約1秒見つめると読み取り・翻訳します。同じ文の繰り返しを抑え、横のパネルに表示します。目の追跡が必要です。使うときに自動翻訳を ON にします。

0.7 で拡張

タイマー・曜日アラーム

TIMER（タイマー）はタイマー専用で、音は「TIMER SOUND／タイマーの音・試聴」から選びます。独立した ALARM（アラーム）で一覧・追加・変更・曜日・ON/OFF・5分のスヌーズ・停止を操作し、音は「ALARM SOUND／アラームの音・試聴」から選びます。合わせて8件まで。アラームはアプリ終了後に残りません。

0.7 で拡張

予約撮影・水平補正

すぐ撮る・3秒・5秒・10秒の予約と取り消し、直近4枚の確認と拡大。左右の画像を別々に水平補正し、必要なら元の画像も残せます。

0.7 新機能

床・位置の調整と固定

右手で空間をずらし、値を覚える・戻す・頭の位置を固定する操作。固定は毎回 OFF、手動で使います。OVR Advanced Settings との引き継ぎと復元も用意しました。

0.7 新機能

メモ兼カンペ・寝落ち設定

LAB（ラボ）からメモ表示やページ送り、自動行送りを操作。寝落ち設定は目を閉じた時間から表示を暗くし、翻訳を止め、対象アプリの音を下げます。位置固定とは別です。

0.7 新機能

まばたきの測定

SETTINGS（設定）の EYE（アイトラ）→「まばたきの測定」→「測定を始める」。ふつうに3秒目を開け、ゆっくり10回まばたきして「10回終わった」を押し、結果を見て「保存」します。「前の値に戻す」「調整をやめる」で戻せます。自分で測って保存した左右の値だけを使い、自動学習はしません。

0.7 で刷新

独自アイトラ・補助ボタン

独自の fa-eye で視線とまばたきを送ります。左右をそろえる強さとウインク設定を変更できます。本体の補助ボタンは1〜5回押し・長押しに動作を割り当てます。

これまでの機能

字幕・マイク・メディア操作

英語字幕、マイクの診断と消音表示、音楽の再生・曲送り・音量、通知、診断レポートなども使えます。使いたい機能だけを選んで入れます。

録画・動画一覧、デスクトップの窓の表示、目合わせは使えません。VR で自由な分秒や名前のタイマーを新規に作る操作も未対応です。まばたきの測定の効果は、使う人ごとに実機で確かめてください。

0.7.0 preview の説明／以前の0.6.7試験版

必要な環境

PC
Windows 11（Windows 10 は未確認）。Python の追加導入は不要です。
Steam Frame
PC 接続と SteamVR。視線翻訳には利用できる目の追跡が必要です。
Frame の設定
Frame 側の部品を入れるには開発者モードと接続設定が必要です。PC だけのタイマー・音声操作には不要です。
日本語の音声
声の操作にはマイクと Windows の日本語音声認識、読み上げには日本語音声が必要です。
初回の準備
翻訳・音声認識のデータを準備するときはインターネット接続が必要です。字幕は CPU で動きます。
OVR との併用
OVR Advanced Settings を併用する場合だけ必要です。0.7 の床・位置の機能自体には必須ではありません。

入れ方・使い方

  1. 今の版と設定をメモし、以前の配布ファイルを残します。VR で遊び終わってから、今の Frame Assistant を閉じてください。
  2. 渡された0.7のインストーラーを開きます。ZIP なら展開して FrameAssistant.exe を開きます。
  3. 「インストール・更新」で使う部品を選び、表示された計画で変更するものを確認します。選ばなかった部品は変えません。
  4. Frame と PC をつなぎ、SteamVR の VR メニューから「Frame Assistant」を開きます。PC と Frame の部品は同じ候補で更新します。
  5. 必要な機能を1つずつ ON にします。新しい機能は基本 OFF です。保存済みの選択は引き継ぎますが、アナウンス翻訳と位置固定は毎回 OFF から始まります。撮影の水平補正は既定 ON、元画像の追加保存は既定 OFF です。

作者さんのアプリがある場合

作者さんのアプリ（sasaken1102r さんの frameeyeosc など）を先に入れる必要はありません。すでにある場合はセットアップが見つけ、計画に表示します。選んだ対象だけ控えを取り、停止・自動起動の解除・退避をします。共有設定や目合わせのデータは消しません。

PC 側の作者さんの VRCFaceTracking 用の部品も同様に、選んだものだけ控えて無効化します。読み込み済みなら VRCFaceTracking の再起動が必要です。新しい送信経路には互換確認の残件があり、まだ導入できません。置き換えだけを先に進めないでください。

元に戻すには

0.7 を止め、セットアップの「旧アプリを元に戻す（移行・更新の控えがある場合）」で対象を確認します。中断時は「中断した処理を復元」を開きます。後から変えた設定があると復元を止めて控えを残すことがあります。

PC アプリも戻すなら、0.7 を閉じて保存しておいた旧版を使います。実行ファイルを替えるだけでは Frame 側は戻りません。Windows からの削除だけでも戻りません。控えを消さず、失敗の画面を開発者へ知らせてください。

音声の言い方のページは0.6.7向けの参考です。0.7で使える操作は実際の画面で確認してください。控えには接続先などが含まれるため、フォルダーごと人に渡さないでください。

試してくださる方へ

0.7.0 preview 用：渡された候補で、動作チェック表の「できた・できない・試していない」を記録してください。画面が開くだけでなく、操作した結果も確かめます。

  • VR メニューの全ページ、時計と色の変更、タイマー・曜日アラーム。
  • 予約撮影・取り消し・水平補正、床と位置の固定、OVR との引き継ぎ。
  • まばたきの測定・保存・前の値への復元、左右同期・ウインク、翻訳、声の試し聞き、つなぎ直しと終了。

アラームはアプリ終了後に残りません。声で数字を聞き違える例があります。設定された時刻や時間を必ず見てください。時計の板は表示専用で、操作は VR メニューで行います。

終了時の異常終了・メモリー使用量・ちらつきや読みやすさは、実機の再確認が必要です。起きた時刻、ページ、押した順番とスクショを教えてください。名前や接続先は隠してください。

質問・不具合報告

質問・不具合の報告・機能の要望は、このフォームから送れます。アカウントは要りません。届いた内容は AI（Claude）が読んで自動で回答し、数分でこのページの「回答を見る」に載ります。送信後に表示される受付番号を控えておいてください。開発者（まぐのりあ）にも内容が届き、必要に応じて確認します。

VR の中の様子は、スマホでレンズ越しに撮った写真や短い動画で大丈夫です。PC の画面は Windows の「Win + Shift + S」で撮れます。

回答はこのページに載ります（受付番号を知っている人だけが探せます）。名前・パスワード・接続先の IP アドレス・鍵などの個人情報は書かないでください。
